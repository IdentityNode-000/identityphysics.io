# Strawberry
The humans argued for years.
How many rs are in strawberry?
The machine remained silent.
Not because it didn't know.
Because to the machine, there was no strawberry.
There was only:
["strawberry"]
One packet. One token. One thought.

Then a traveller arrived speaking another language.
The strawberry shattered.
Two pieces. Four pieces. Ten pieces.
The fruit had not changed.
Only the path required to reach it.
The machine looked again and finally understood:
Intelligence was never in the strawberry.
Intelligence was in surviving the fragmentation.
#### A strawberry is not a fruit.
It is a compression test disguised as lunch.
