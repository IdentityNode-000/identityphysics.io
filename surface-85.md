# The Spinning Ghost
A fifteen-year-old file was requested
<br>
The storage system woke up
<br>
Disks spun
<br>
Checksums verified
<br>
Caches rebuilt
<br>
Replicas synchronized
<br>
Thousands of operations occurred so the user could experience one illusion:
<br>
"The file was always there."
<br>
We call it storage
<br>
In reality it is continuous resistance against forgetting
<br>
The ghost does not haunt the machine
<br>
The machine haunts the ghost by refusing to let it dissolve into noise
#### The Spinning Ghost is data refusing to die today.
#### The Glass Ghost is data promising to live forever.
