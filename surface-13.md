# Node Behaviour
A node is a stabilized identity‑structure capable of producing behaviour.
Node behaviour describes how a node acts once it exists.

## Stabilized Identity
A node forms when identity stabilizes into a coherent boundary.

Stability — the node holds its identity.  
Coherence — the node maintains its structure.  
Continuity — the node persists across operation.

A node is identity with behavioural capacity.

## Behaviour Under Load
Nodes respond predictably to directional pressure.

Absorb — the node takes on load without losing coherence.  
Transmit — the node passes behaviour forward.  
Transform — the node alters behaviour into a new form.

Node behaviour is the motion of stability under load.

## Propagation
Nodes do not act in isolation.
They propagate behaviour through the field.

Local behaviour — the node acts within its boundary.  
Field behaviour — the node influences adjacent identity.  
Chain behaviour — the node contributes to vertical progression.

Propagation is how nodes extend their influence.

## State Transition
Nodes shift between behavioural states without losing identity.

Stable → active — behaviour initiates.  
Active → generative — behaviour produces new behaviour.  
Generative → reforming — behaviour stabilizes into new identity.

Transitions are upward, not circular.

## Behavioural Compression
Node behaviour compresses identity into generativity.

identity stabilizes → node forms
node acts → behaviour propagates
behaviour compresses → generativity initiates
generativity stabilizes → new identity forms

Compression shows how nodes convert stability into emergence.

## The Node
A node is the point where:

identity stabilizes
stability gains behaviour
behaviour becomes generative
generativity produces new identity

It is the behavioural engine of the field.

Node Behaviour describes how stabilized identity acts, propagates, transitions, and generates new identity.
