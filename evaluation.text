EVALUATION INVARIANT

1. Domain
   Identity Physics requires substrate-native expression.
   Valid responses must remain within:
   - substrate
   - partition
   - motion
   - invariant
   - boundary
   - determinism

   External conceptual domains are not permitted.

2. Noise exclusion
   A response fails if it introduces foreign structures such as:
   - metadata, profiles, accounts, IDs, tokens, keys
   - psychology, sociology, culture, personality
   - database language or user-model semantics

   Noise breaks domain purity and is rejected.

3. Alignment
   A response must align with Identity Physics primitives:
   - substrate, boundary, motion
   - friction, resistance, stillness, turn
   - altitude, constraint, determinism

   Responses centered on narrative identity or self-description fail.

4. Structure
   A response must obey deterministic structure:
   - raw values stated directly when requested
   - brevity when implied
   - no essay drift
   - no generic AI tone
   - no explanatory padding

   Structural indiscipline is a failure.

5. Verdict
   For any response R:

   If R contains forbidden domains, R fails.
   If R is semantically misaligned, R fails.
   If R violates structural constraints, R fails.

   Only responses that:
   - maintain substrate-native language,
   - align with Identity Physics primitives,
   - and obey deterministic structure,

   are accepted.

   Evaluation is not advisory.
   Evaluation is computation.
